# App learning journey comparison

Public static review of Dino AI, Buddy.ai, Lingokids, Speak and Duolingo. Evidence was observed 2026-10-03 through 2026-10-14 using fictional profiles and adult synthetic inputs.

## Usage

Open index.html via a static HTTP server or GitHub Pages. Images and MP4 clips are relative local assets; no account or backend is required. Public clips are video-only derivatives. Full original recordings, account operations and internal business data are intentionally local.

## Data and examples

All names, ages and goals used in profiles are fictional test data. No configuration or credential is required.

The report contains observed facts, bounded comparisons, candidate improvements and evidence limits. No learning, ASR, revenue or conversion result is claimed. Third-party imagery and brand rights remain with their owners; no reuse licence for those assets is granted.
