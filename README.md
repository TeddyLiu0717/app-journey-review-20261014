## 完整录屏怎么用

1. 打开完整录屏目录，选择 App 和录制文件，可在线播放完整 MP4。
2. 下载该段的 `-full.html`，用 Chrome 或 Edge 打开。完整视频内嵌在 HTML 内，复制给同事后可断网播放，不依赖原片目录、登录或临时视频地址。
3. `-original.mkv` 是字节不变的原始录制，适合下载保存；`-full.mp4` 与 HTML 内嵌视频是保留全部帧的浏览器观看副本。

完整目录覆盖21批次、50段文件，约14.4小时（含原有等待和音轨尾段）。49段提供原始 MKV；一段包含账号邮箱，原件保持私有，仅公开局部遮盖邮箱、保留全部时长的副本。每段详情显示文件校验值和声音情况。

14段原始文件没有音轨，3段接近静音，其余保留原有音轨内容，声源和同步未确认。完整文件保留录制中的等待、重试、旋转和诊断；跨文件的录制空档没有补造。完整文件不表示所有业务模块均已正常成功。
