# App journey review

Five-app illustrated experience report with 90 observed interaction nodes, eight overlapping modules, and five full chaptered videos.

Open [the complete report](https://teddyliu0717.github.io/app-journey-review-20261014/) or [the full-video page](full-recordings.html). Media is available without sign-in. Download complete-report.html for a shareable report; images and short previews are embedded, while the five full MP4s load from the public release or an adjacent videos folder.

These are representative, cross-session free-flow observations recorded on 3–14 October 2026. Child and adult products are compared only for transferable interactions. Real children, learning gains, ASR quality, payment outcomes and cloud synchronization are not established. Some paths failed or were access-limited.

The public package is separately reviewed. Original sources remain preserved locally; one source containing an account email is shared only as a full-duration masked derivative. No private account details, local paths, private source repositories, or internal business data are included.
